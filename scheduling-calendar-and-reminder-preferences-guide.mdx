This video explains how to create and manage therapist scheduling events and set client reminder preferences in the Direct Care scheduling app. It covers using filters like event status, category, clients, and views by weekday, week, list, or month, plus hovering to add events in 15 minute increments, setting repeatable schedules (weekly or every two weeks with custom day selections), and using the today button to return to the current date. It also shows setting event reminders on the client contact preferences to send email or text, selecting an email address and choosing reminder days, then saving so guardians receive automated emails. It also demonstrates how to delete either a single event or all events in a repeatable series, and how a scheduling admin can create and send reminders for staff across all schedules.
