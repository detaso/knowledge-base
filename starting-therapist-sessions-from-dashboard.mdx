As a therapist, you can start a session straight from an upcoming event on your dashboard. This article shows how to schedule an event and then start it from the dashboard.

Video length: 1:07

## How it works (0:00)

After you add an event to your schedule in the detaso scheduling app, it shows up on your dashboard. When the event is close to its start time, you can click it to start the session.

- You can only start a session within 15 minutes of the event's start time.
- If you click an event that's further away, no session is available yet.

## Schedule an event (0:22)

1. Open your **Schedule**.
2. Create a new event and set the start time.
3. Select the **Location**.
4. Select the **Treatment**.
5. Click **Save**.

## Start the session from your dashboard (0:38)

1. Go to your **Dashboard**.
2. Find the event under your upcoming events.
3. Click the event, then click **Start**.

When the session opens, some details fill in for you:

- **Start time** is set to the current time.
- **Estimated units** are filled in. You can change them if you need to.
- **Location** and **Place of service** come from the event you created in the scheduling app.

**Tip:** Add your events to the schedule ahead of time. That way, everything's ready to start from your dashboard when the session begins.
